# Web Demo UMKM

Kumpulan demo website untuk UMKM di Solo Raya yang belum punya website.
Dibuat oleh Erza (Muhammad Erza Al-Isyrafy), web developer.

Situs live: https://erzarafy.github.io/web-demo-umkm/

## Isi repo

- `index.html` — halaman daftar semua demo
- Satu folder per demo, masing-masing berisi satu file `index.html` mandiri:
  - Salon & barbershop: `kinanti-salon`, `dr-hair`, `oesmans-barbershop`,
    `proper-barbershop`, `goodfriends-barbershop`, `el-barbershop`,
    `five-o-barbershop`, `smooch-beauty-bar`
  - Klinik & kesehatan: `christianie-dental-care`, `aa-dental-care`,
    `dental-solution-solo`, `samudra-vet-care`
  - Wedding & catering: `sakinah-katering`, `obong-management`,
    `harmoni-wedding`, `de-lawang-djoendjing`
  - Otomotif & rental: `trisno-motor`, `diral-motor`, `rka-transport`
  - Resto: `manara-bistro`, `yassalam-resto`
  - Retail & lainnya: `batik-putra-bengawan`, `amalia-furniture`,
    `toko-mas-dinar`, `doeloerkoe-homestay`, `neo-fit-gym`

## Catatan

- Semua data bisnis di demo berasal dari sumber publik (Google Maps,
  Instagram, dan kanal resmi bisnis terkait). Harga, jam, dan rating yang
  tidak terverifikasi sengaja tidak ditampilkan.
- Foto-foto di dalam demo adalah ilustrasi; foto asli menyusul dari bisnis
  yang bersangkutan setelah mereka setuju.
- Demo ini dibuat sebagai bahan penawaran jasa pembuatan website.
  Bisnis yang setuju akan dibuatkan website di hosting sendiri setelah
  pembayaran, lalu kendali diserahkan.
